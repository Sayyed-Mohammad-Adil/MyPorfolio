# Sayyed Mohammad Adil - Developer Portfolio

Welcome to the source code for my personal developer portfolio! This project showcases my skills, experience, and love for clean code, open source, and interactive web experiences.

Check out the live version: [www.sayyedmohammadadil.online](https://www.sayyedmohammadadil.online/)

## ✨ Key Features

- **Modern & Premium Design**: Built with a sleek, vibrant aesthetic, glassmorphism, and a polished dark/light mode toggle.
- **Interactive Contribution Grid**: A completely custom GitHub-style contribution graph that features a live, animated snake! 
  - The snake eats the contributions to spell "CODING".
  - After completing its path, it slithers backward to build a massive **Winner's Trophy**.
  - The Trophy sparkles dynamically with colors matched to the current theme!
- **Responsive Layout**: Designed mobile-first, ensuring an excellent viewing experience on phones, tablets, and desktop displays.
- **Micro-Animations**: Smooth hover states, glowing shadows, and tailored transition effects that bring the interface to life.

## 🛠️ Technology Stack

- **React.js**: For component-based UI architecture.
- **Tailwind CSS**: For utility-first styling and seamless responsive/theme design.
- **Lucide React**: Beautiful, crisp SVG iconography.

## 🚀 Running Locally

If you'd like to fork and run this project locally to explore the code:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will launch locally (usually on `http://localhost:5173`).
